# AI Study Assistant

An AI-powered study assistant that allows students to upload PDF notes and interact with them intelligently.

## Features
- PDF Chat
- AI Summaries
- Quiz Generation
- Important Questions Extraction

## Tech Stack
- Python
- LangChain
- FAISS
- Streamlit
- Gemini API
